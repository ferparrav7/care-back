# 🏥 Care Backend

Backend API for a healthcare appointment system built with **FastAPI** ⚡

## 🧰 Tech Stack
- FastAPI 🚀
- Python 3.13 🐍
- PostgreSQL 🐘
- SQLAlchemy
- Uvicorn

## ▶️ Run locally
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn storeapi.main:app --reload
